    How episodes are made

    1. Sources first. A list of sources is fixed and approved before a script is written, and every source is confirmed in a registry or in a company's own published release. Nothing is added afterwards.
    2. Claims are checked against those sources. Programs read the finished script and refuse it where it names a work that is not on the list, credits a source with something its own text does not say, or asserts a history, a consensus or a judgement that no listed source states.
    3. The status is stated plainly. The wording for each source's standing is written by the pipeline from that source's record — peer reviewed, a preprint, or a company release that has not been peer reviewed or independently checked — and the script must carry it once, in those words.

    This describes the pipeline as it runs today, not a plan.
